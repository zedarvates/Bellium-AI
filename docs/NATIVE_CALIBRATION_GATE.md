# Native micro-NN calibration gate - 9 October 2026

Native softmax classifiers now have an explicit stdlib-only temperature calibration
API. This gate produces a negative result for both evaluated routeurs: fitting
improves calibration-split loss but does not improve the fresh evaluation split.
No correction is enabled by default, and no weights or confidence thresholds change.

## Method and numerical behavior

Temperature scaling divides the final logits by a positive scalar before softmax,
following [Guo et al., On Calibration of Modern Neural Networks (ICML 2017)](https://proceedings.mlr.press/v70/guo17a.html).
It adjusts scores rather than retraining the classifier. The local implementation
uses logits directly, avoiding loss of information from clipped zero probabilities.
A test with logits [1000,-1000] and the wrong target verifies NLL=2000 rather than
a capped loss derived from an epsilon probability floor.

`bellium.micro_nn.calibration` provides:

- `predict_logits(model, vector)`: final pre-softmax values through the existing
  inference engine, with a copied activation list and no model mutation.
- `fit_temperature(model, calibration_samples)`: bounded scalar search over
  T in [0.1,10], minimizing mean NLL. Identity and both boundaries are always
  considered; all model classes require calibration support. The artifact records
  class counts, pre/post fitting loss and whether the optimum hits a bound.
- `probability_metrics(logits, labels, ...)`: NLL, multiclass Brier score (sum
  across classes, mean across samples), ten-bin ECE, per-class NLL/Brier with
  explicit support, reliability bins, coverage and selective accuracy.
- `predict_calibrated(model, vector, artifact)`: explicit application after schema,
  class-count, positive-temperature and model-fingerprint checks. Numerical loss
  of argmax ordering is rejected. Metadata, labels and weights are all bound by
  the canonical sorted-JSON fingerprint; even a metadata change requires refitting.

Logit vectors/labels must be non-empty, aligned, dimension-consistent and finite;
labels must be valid integer class indices. Empty reliability bins and unsupported
evaluation classes expose null metrics. Temperature scaling does not fix class
errors, domain mismatch, missing evidence or distribution shift. Finite extreme
values that overflow scaling arithmetic are rejected rather than clipped silently.

No calibration file is automatically loaded or written. The historical legacy
calibration implementation is preserved for compatibility.

## Optional tool-router application

```python
from bellium.micro_nn.calibration import fit_temperature
from bellium.micro_nn.mlp import load_mlp
from bellium.specialists.tool_router import MODEL_PATH, classify_tool_need

model = load_mlp(MODEL_PATH)
artifact = fit_temperature(model, labeled_calibration_samples)
# Evaluate separately before opting in with an application-owned artifact.
result = classify_tool_need(query, calibration=artifact)
```

Both `classify_tool_need` and `route_tool` accept the optional artifact. Fractional
flags still abstain before model/calibration inference; deterministic veto still
returns before consulting the network. A supported query with a mismatched artifact
raises instead of silently using raw scores. Applied results identify the method,
temperature and fingerprint in their output. Calling without an artifact keeps
the previous probabilities, decision path and 0.55 abstention threshold.

## Frozen synthetic experiment

Existing distributed tool-router and inpaint-router weights are used without
training. Each model has 1,500 calibration samples (seed 2026100901) and 2,500 fresh
evaluation samples (seed 2026100902), generated by its existing synthetic rule.
Feature overlap is checked against each other, the current trainer's generated
train/held-out splits and the prior 20261009 evaluation seed. No private logs are
read and no field labels are claimed.

Acceptance criteria are declared before fitting: at least 2% relative evaluation
NLL improvement, no overall Brier regression, ECE increase <=0.001, coverage drop
<=0.02, selective accuracy drop <=0.002, unchanged decisions, at least 50 evaluation
samples per class, per-class NLL increase <=0.01 and Brier increase <=0.002, and an
optimum away from the search bounds. Evaluation results do not choose the fit or
retune its bounds.

| Model | Fitted T | Calibration NLL before / after | Evaluation NLL before / after | Evaluation ECE before / after | Gate |
| --- | --- | --- | --- | --- | --- |
| Tool router | 1.2177 | 0.025385 / 0.024588 | 0.018171 / 0.018274 | 0.003050 / 0.004211 | Reject |
| Inpaint router | 1.4079 | 0.044946 / 0.042250 | 0.034753 / 0.035467 | 0.001949 / 0.004640 | Reject |

Tool-router evaluation Brier improves (0.011296 ->0.011009) but NLL and ECE fail.
Inpaint evaluation Brier also regresses (0.020225 ->0.020461), including its minority
class beyond the declared tolerance. The tool and inpaint argmax accuracies remain
99.16% and 98.6%, respectively. Their unchanged 0.55 cutoff changes accepted counts
from 2496 to2495 and from2491 to2487 when the experimental scores are explicitly
applied. Neither artifact is promoted or saved into distributed model resources.

This is one generated split pair per model. ECE depends on binning and small error
counts; the result does not prove temperature scaling is always harmful or useful.
These are rule-fidelity probabilities, not calibrated real-world correctness.
